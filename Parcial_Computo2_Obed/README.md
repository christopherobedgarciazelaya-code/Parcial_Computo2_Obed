## Descripción del Proyecto
Aplicación desarrollada en Python que integra el análisis de datos mediante **Pandas**, visualización gráfica con **Matplotlib** y una interfaz de escritorio construida en **PyQt5** para el control de inventario de una empresa salvadoreña con cinco sucursales.

## Estructura de Archivos
- `app.py`: Código fuente principal de la aplicación gráfica y análisis de datos.
- `datos.csv`: Base de datos del inventario por sucursal.
- `requirements.txt`: Dependencias del proyecto.
- `Informe_Consultoria.pdf`: Informe detallado de consultoría de datos.
